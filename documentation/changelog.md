# Changelog

## v1.0.0 — 2026-11-19
- Initial production release of **LifeBridge Institute of Nursing & Paramedical Sciences** multi-page template.
- Built 19 public HTML5 pages, 10 Student LMS Dashboard pages, and 1 Admin Blueprint scaffold.
- Sourced, resized, compressed, and converted **101 unique local photographs** into optimized `.jpg` and `.webp` pairs inside `assets/images/`.
- Implemented custom "Clinical Calm meets Pulse" design system with CSS logical properties, Dark/Light mode, full RTL mirroring, print stylesheet, and minified production assets.
- Added 3D perspective tilt engine (mouse glare + touch scroll-tilt), healthcare-themed card micro-animations, interactive ICU Simulation Lab hotspots, Course Comparison Tool, 5-step Admissions form with localStorage draft save, SVG charts, Command Palette (`Ctrl/Cmd+K`), 3-Question Course Quiz, and WCAG 2.1 AA form validation.
